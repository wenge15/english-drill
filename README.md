# 英语练习 · English Drill

一个单机英语单选练习软件：**录题 → 每日练习 → 错题复习**。

练习形式刻意做成"**练完才揭晓**"：点击选项后不告诉你对错，全部做完才公布正确率，然后带你重做错题。
复习节奏用遗忘曲线调度，手感接近墨墨背单词。

**零依赖**：只用 Node 内置模块（`node:sqlite` / `node:http`），没有 `npm install`，没有构建步骤。

## 它解决什么问题

1. **录题太麻烦** —— 试卷照片/文字粘进去就行，自动拆出题干、选项、答案
2. **不知道自己哪里弱** —— 录入即自动标注考点，按考点统计正确率
3. **错了记不住** —— 按遗忘曲线安排复习；同一道题错到第二次，就地讲评并可以追问

## 环境要求

- **Node.js ≥ 22.5.0**（需要内置的 `node:sqlite`）
- 想要独立桌面窗口观感的话，需要 Edge 或 Chrome；没有就退化用默认浏览器

**不需要 API Key 也能完整使用。** 配 Key 只影响两个可选功能（见「数据与隐私」）。

## 快速开始

```bash
git clone <仓库地址>
cd english-drill
npm start
```

`npm start` 会：起一个只监听 `127.0.0.1` 的服务 → 等它就绪 → 用 Edge 的应用窗口打开界面。

其他命令：

```bash
npm run serve      # 只起服务，不打开窗口（开发时常用）
npm test           # 跑全部单元测试
npm run test:http  # 端到端测试（需要先 npm run serve）
```

Windows 上也可以直接双击 `启动英语练习.vbs`（它会隐藏窗口启动服务并打开练习窗口）。

**第一次用**：点界面里的「试用：导入 6 道示例题」，就能立刻体验练习和复习流程。

## 录题：三种方式

### ① 文本导入（主路径，不需要任何 Key）

把题目**文本**粘进「录入题目 → 文本导入」，解析器负责拆出题干、选项、答案：

```
21. He ____ to school by bus every day.
A. go
B. goes
C. going
D. gone
答案：B

22. The report ____ by the team last week.
A. completes  B. completed  C. was completed  D. has completed
答案：C
```

容错做得比较宽，下面这些都能认：

| 情况 | 支持 |
|---|---|
| 选项竖排 | `A. go` / `A) go` / `A、go` / `（A）go` |
| 选项横排 | 同一行的 `A. completes  B. completed  C. was completed` |
| 答案写法 | `答案：B`、`正确答案是 C`、`Answer: B`、纯字母 |
| 答案独立成表 | 「答案表」输入 `1-5 BCDAB` 或 `21-B 22-C` |
| 全角标点 | 全角冒号、括弧、顿号 |
| 中文题干 | 题干里的中文不影响选项切分 |

> **省事路径**：如果你有试卷照片，把它发给任何能读图的模型，把识别出的文字粘进这里即可。

### ② 图片识别（备用，需自备 Key）

「录入题目 → 图片识别」，需要配一个**能读图**的模型。

**最省事：用 DeepSeek 自己的 `deepseek-flash`** —— 它支持图片输入
（JPEG / PNG / GIF / WebP，[官方文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)）。
在设置页点「DeepSeek」预置即可，填上 Key 就能拍照录入，不用再申请第二家的账号。

也可以换智谱 `glm-4v-flash`、通义 `qwen-vl-max`、OpenAI `gpt-4o`，
或本地 Ollama（`qwen2.5vl:7b`，完全离线）。

### ③ 手动录入

少量题目直接敲，可一键让模型补答案与知识点。

## 批量删除题目

两个地方都能自选题目、一键删除：

| 位置 | 用途 |
|---|---|
| **录入题目 → 核对页** | 删掉**还没入库**的题（勾选 / 全选 / 删除选中的 / 全部清空） |
| **题库管理** | 删掉**已入库**的题（勾选多题批量删，或每道题右侧单独删） |

删除分两种，界面会明确区分：

- **删除**（默认）＝移入**回收站**，从题库和练习中消失，但**数据还在，可随时恢复**
- **彻底删除**＝从数据库抹掉，**连同这道题的全部作答记录与复习进度，不可恢复**

彻底删除前会先告诉你影响范围（例如"会一并删除 12 条作答记录、涉及 3 次练习"）。
「回收站」页可以查看、勾选恢复、彻底删除，或一键清空。

## 单元分组：按单元看清掌握情况

录入时可以指定分组（填新名字自动创建），也可以事后在「题库管理」里勾选批量归类。

「单元分组」页按掌握度排序，每个单元给出：题量、已学、待复习、累计错题、掌握度，
以及该单元的**高频考点**。支持新建、改名、删除（删除不会删题，只是转为未分组）。

## 考前集训：一周内把错过的题过一遍

「今日练习」页有「考前集训」：把**所有做错过的题**排进指定天数（默认 7 天）复习一遍。

- 只针对**错过至少一次**的题，不掺入没做过的新题
- **错得最多的排最前**，优先复习最不熟的
- 保证**一道错题都不漏**（题多时超出每天上限的部分并入最后一天）
- 可以先「查看排期计划」预览每天多少题、主要考什么，再决定开始
- 天数可选 3 / 5 / 7 / 14 天，每天题量上限可选 20 / 30 / 60 / 120

## 练习页的两条交互规则

1. **题号只在练习时出现**：练习页显眼位置显示「第 N 题 / 共 M 题」；录入与核对时不显示。
2. **第二次做错就地展开讲评**：第一次错照旧不揭晓（直接下一题）；
   同一道题**累计错到第 2 次**时，**在题目下方**就地展开（不遮挡题目）：
   - 你这次选了什么、正确答案是什么
   - 这道题的考点
   - **你前几次分别选了什么**（按时间列出）
   - 「这次和上次选的是同一个选项」的提醒（说明不是手滑，是没掌握）
   - **内嵌对话窗口** —— 直接就这道题提问（自动带上题干、选项、考点、作答记录），
     或一键复制内容去问别的 AI

## 练习与复习

- **每日队列**：按遗忘曲线排出今天该复习的题，加上少量没学过的新题
- **乱序**：题目顺序、选项顺序都可以每次随机（设置里可关）。
  所以同一道题这次正确答案是 A，下次可能变成 C
- **不揭晓**：练习中不提示对错，做完才给正确率和错题解析
- **错题重做**：结算后可以直接重做本轮错题，直到全对
- **记忆调度**：基于 FSRS 形状的遗忘曲线，目标保持率默认 0.9
  （连对 10 次的实际间隔：3 → 3.7 → 4.6 → 5.8 → 7.3 → 9.2 → 11.7 → 14.8 → 18.7 → 23.8 天）

## 知识点：录入即自动标注

录入时会用**本地规则**自动标注考点（不需要 Key），覆盖 20 多类：

定语从句、被动语态、虚拟语气、现在完成时、过去完成时、一般过去时、一般现在时、
一般将来时、现在进行时、非谓语动词、情态动词、主谓一致、介词搭配、固定短语、
短语搭配、宾语从句、状语从句、冠词、代词、比较级与最高级、名词单复数、熟词生义、词义辨析

设计上**宁可漏标也不误标**：错标会污染"薄弱项"统计，漏标只是少一个标签。
`test/knowledge.test.js` 里锁了一批容易误判的边界情况。

配置了文本模型时，模型会在本地标签**之后**追加更贴切的考点名（不覆盖本地标签，保证统计稳定）。

### 词汇题：逐项释义（内置释义库，不需要 Key）

词义/短语辨析题会**为每个选项分别给出**：

| 项 | 说明 |
|---|---|
| **常用义** | 这个词最常见的意思 |
| **其它义** | 其它常见义项 |
| **熟词生义** | 常见词的**不常见含义**（如 address 常义"地址"，在 address the issue 里是"处理"） |
| **本题意思** | 在**这一题**的语境下具体取哪个意思 |
| **短语释疑** | 短语的构成拆解 + 整体意思（如 take off = take（拿）+ off（离开表面）→ 起飞／脱下） |
| **提示** | 易混点、搭配要求（如 borrow 接 from、lend 接 to） |

内置释义库覆盖：时间与介词易混词、熟词生义、常见短语动词、动词+介词搭配、近义词辨析。

- **未收录的词不会编造释义**，而是明确告知"未收录：xxx"，并给出复制入口
- 配了文本模型时，模型只用来**补本地没有的词条**（本地释义优先，更可靠）

## 问答窗口

「问答」页可以问语法/词汇问题。配上文本模型后能直接回答；
没配 Key 时它会明确告知，并提供「复制这道题的内容」让你带去问别的 AI。
提问会自动带上题目上下文（题干、选项、考点、你的作答历史），不用重复描述。

## 数据与隐私

**所有数据都在本地**，没有账号、没有云端同步、没有遥测。

- 数据目录：项目下的 `data/`（数据库 `questions.db`、`images/`）
- 服务**只监听 `127.0.0.1`**，并校验访问令牌（存在 `data/.shell-token`），
  避免本机其它程序白嫖你的模型额度
- `data/` 已在 `.gitignore` 里，不会被误提交

### 需要 API Key 的两个可选功能

| 功能 | 不配 Key 时 |
|---|---|
| **应用内问答** | 会明确说"暂时无法回答"，并给「复制内容」按钮 |
| **图片识别录题** | 无法使用；可以用别的能读图的工具识别后走文本导入 |

Key 存在本地数据库里，界面上只显示掩码（如 `sk-s****`）。

**只有 `src/core/model.js` 会发起网络请求**，其他模块全部离线。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 每日新题上限 | 20 | 控制每天引入多少没学过的题 |
| 每日总题上限 | 200 | 防止积压太多时一次做不完 |
| 目标保持率 | 0.9 | 越高复习越频繁 |
| 题目乱序 | 开 | 每次练习顺序随机 |
| 选项乱序 | 开 | 每次练习选项顺序随机 |
| 模型配置 | 空 | baseUrl / apiKey / 文本模型 / 读图模型 |

## 技术说明

```
src/
  host.js           业务动作表（channel → 处理函数）
  shell-http.js     开发用外壳：HTTP 服务 + 从磁盘读界面
  shell-server.js   HTTP 层共用实现
  launcher.js       启动器：确保服务在跑，然后开窗口
  core/
    srs.js          间隔重复算法（纯函数）
    db.js           数据层：表结构、迁移、查询（node:sqlite）
    textparse.js    文本导入解析
    knowledge.js    知识点识别
    glossary.js     本地释义库
    extract.js      读图结果解析与归一化
    model.js        OpenAI 兼容接口适配（唯一联网模块）
desktop/renderer/index.html   整个前端（单文件，零构建）
test/                         每个模块一个测试文件 + run-all.js
```

**分层原则**：界面只调用 `window.dsh.invoke(channel, args)`；外壳负责转发给 `host.js` 的动作表；
业务逻辑不碰 HTTP 也不碰 DOM。换外壳时业务代码一行都不用改。

开发中的决策与踩过的坑记录在 [`STATUS.md`](STATUS.md)；参与贡献请先读 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
